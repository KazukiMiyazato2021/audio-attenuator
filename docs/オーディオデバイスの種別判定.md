# オーディオデバイスの種別判定

出力デバイスを自動選択するとき、「仮想デバイスでないもの」という条件だけでは
不十分だった。

## 問題

macOS には Audio MIDI 設定で作られる「機器セット(Aggregate Device)」や
「複数出力装置(Multi-Output Device)」がある。これらは仮想デバイスではないため、
`transportType != Virtual` という条件を通過してしまう。

自動選択がこれらを掴むと、音がどこにも出ない状態になる。しかも**エラーは出ない**。
リレーは正常に動作しているように見える。

## 判定

`kAudioDevicePropertyTransportType` で区別する。

| 種別 | transportType | 自動選択 |
|---|---|---|
| 物理デバイス | `BuiltIn` / `Bluetooth` / `USB` など | 対象 |
| 仮想デバイス | `kAudioDeviceTransportTypeVirtual` | 除外 |
| 機器セット・複数出力装置 | `kAudioDeviceTransportTypeAggregate` | 除外 |

Aggregate 系は**他のデバイスの上に構築される**ため、自分自身の仮想デバイスを
含んでいる可能性がある。自動選択で掴むと出力が入力へ戻りかねない。
ユーザーが明示的に選べるようにはしておき、自動では選ばない。

物理デバイスの中では `BuiltIn` を優先すると無難。

## 自分自身を除外する

ミキサー自身も出力デバイスへ書き込むため、プロセス一覧に「再生中」として現れる。
これをタップ対象として提示すると、自分の出力を自分の入力に戻すことになる。

除外は **PID ではなくバンドル ID で**行う。CLI とメニューバー常駐の2つが同時に
動いている場合、PID は異なっても同じアプリだから。
