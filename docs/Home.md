# Audio Attenuator 開発知見

macOS の仮想オーディオドライバ + アプリ単位音量ミキサーを実装する過程で、
実機検証によって判明した事柄をまとめる。Apple の公式ドキュメントが薄く、かつ
**失敗がエラーではなく無音や遅延として現れる**領域が多いため、再現方法と
判定材料を残すことを重視している。

## アプリ単位の音声キャプチャ

- [[Core Audio Process Tap]] — プロセス単位で音声を取り出す API の実際
- [[TCC 権限 - オーディオキャプチャ]] — 2種類の権限。どちらも欠けると無音になる
- [[TCC 責任プロセス]] — 権限は「呼び出し元」ではなく「責任プロセス」で判定される
- [[コード署名と TCC 許可の失効]] — ad-hoc 署名だとビルドのたびに許可が消える

## 出力とサンプルレート

- [[出力デバイスのサンプルレートを強制しない]] — Bluetooth でピッチが狂った原因
- [[HAL Output AudioUnit]] — リサンプリングを任せる

## 遅延

- [[仮想デバイスの遅延申告]] — リップシンクがずれる原因と対処
- [[AudioServerPlugIn のカスタムプロパティ]] — 遅延値をドライバへ渡す手段
- [[リングバッファの遅延管理]] — 一時的に溜まった分は放置すると永久に残る

## ドライバ実装

- [[AudioServerPlugIn の変更通知]] — 値を保存するだけでは誰も気づかない
- [[coreaudiod 再起動への対応]] — 再起動で全オブジェクト ID が無効になる

## デバイスとプロセスの扱い

- [[オーディオデバイスの種別判定]] — 自動選択で Aggregate を掴まない
- [[オーディオプロセスのグループ化]] — ブラウザのヘルパープロセス問題

## 検証

- [[オーディオ検証の落とし穴]] — 見落としを生んだ検証条件の偏り

## 検証環境

macOS 15.8 / x86_64 / Command Line Tools SDK 15.5。
Xcode を使わず CMake(ドライバ)と Swift Package Manager(エージェント)で構成。
